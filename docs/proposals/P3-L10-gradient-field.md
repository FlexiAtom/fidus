## 0. TL;DR

我按 AGENTS §8（判决用的量必须先验证是真代理）和 §2（先推终局）的要求，在写任何代码前用 numpy 实测了 L10 的核心假设。**实测推翻了规格 §4.2 的方案骨架**：

| §4.2 的声称 | 实测 | 结论 |
|---|---|---|
| 对数螺旋网格 → FFT 有"明确峰值" | 峰锐度 **3.4–6.8**（规则光栅 **250.9**），前 100 强频点仅占总能量 1.6–13% | ❌ **没有主频可锁** |
| 相位角 θ → 求解偏移量 | 干净条件下精度 **0.034px**，强纹理壁纸下 **0.060px** | ✅ 极佳，**但只在规则光栅上成立** |
| 该方案可独立产出 `CoordinateFrame` | 相位只确定 `offset mod period`；1366px 宽屏、40px 周期 → **34 个等价解** | ❌ **无法独立定位** |

**核心矛盾（此前无人写下）**：规格把"对数螺旋"和"锁定 FFT 主频"并列为方案的两半，**但二者互斥**——

- **规则光栅**有尖锐主频（锐度 250.9）、相位精度 0.03px，但**存在整周期歧义**；
- **对数螺旋**消除了歧义（实测 NCC 随位移单调下降不回升，全局唯一），**但代价正是摧毁"主频"这个概念本身**——局部频率随位置变化，能量必然弥散。

"用对数螺旋 + 锁定主频"是一个**自相矛盾的设计**。这不是实现难度问题，是原理问题。v0.4 写下它时没有验算，而 P2-f 的三条 Critical 教给我们的正是：**没验算过的"看起来合理"，通常是反的。**

## 1. 实测依据（可复现）

环境：实机分辨率 1366×768（eDP-1），numpy 1.26.4。脚本见本提案附录。

### 1.1 峰锐度：对数螺旋输给规则光栅 **40–70 倍**

锐度定义 = 峰值 / 同半径环上的平均能量（已剔除 DC 附近 7×7）。

| 图案 | 锐度 | 前 100 强频点占总能量 |
|---|---|---|
| **规则光栅**（period=40px） | **250.9** | — |
| 对数螺旋 k=10 | 4.9 | 13.4% |
| 对数螺旋 k=20 | 3.4 | 8.4% |
| 对数螺旋 k=30 | 4.1 | 5.5% |
| 对数螺旋 k=50 | 4.2 | 2.9% |
| 对数螺旋 k=80 | 6.8 | 1.6% |

**结论对所有 k 都成立**（3.4–6.8 vs 250.9），不是某个参数没调好：对数螺旋的"峰"基本是噪声地板里的一个起伏，能量弥散在整个频域，**不存在可锁定的主频**。

> 注意 k 越大、能量越弥散（前 100 点占比从 13.4% 降到 1.6%）——**螺旋越"标准"，主频越不存在**。这说明它不是参数问题，是这个图案的固有性质。

### 1.2 相位 → 偏移：方法本身极其精确，且抗污染

规则光栅（period=40px），在已知主频处取 DFT 相位反推偏移：

| 真实偏移 | 估计 | 误差 |
|---|---|---|
| 1.0 px | 1.01 | 0.006 |
| 3.7 px | 3.73 | 0.026 |
| 10.0 px | 10.03 | 0.034 |
| 17.3 px | 17.29 | 0.007 |
| 39.0 px | 39.00 | 0.004 |

**最大误差 0.034px**。加入壁纸污染（网格与壁纸各占 50% 混合）：

| 背景 | 平均误差 | 最差 |
|---|---|---|
| 无噪声 | 0.041 px | 0.041 |
| 轻纹理 | 0.040 px | 0.042 |
| 中纹理 | 0.041 px | 0.045 |
| **强纹理 / 视频壁纸** | **0.045 px** | **0.060** |

> **这条推翻了规格列出的第二条风险**（"动态壁纸/视频背景的频谱污染"）。窄带相位估计对宽带噪声天然免疫——壁纸能量分散在所有频率，而我们只在**一个**已知频点取值。**L10 真正的问题不是抗噪，是歧义。**

### 1.3 整周期歧义：这才是致命伤

```
偏移    0.0px -> 相位 -1.568124786483 rad
偏移   40.0px -> 相位 -1.568124786483 rad   (差 2.2e-16)
偏移   80.0px -> 相位 -1.568124786483 rad   (差 4.4e-16)
偏移  120.0px -> 相位 -1.568124786483 rad   (差 6.7e-16)
```

差值是 **1e-16 量级的浮点残差**（双精度 eps ≈ 2.2e-16），物理上完全相同。相位是 `mod 2π` 的量，**整周期位移对它不可见**。

**要消歧就需要一个已知位置的参照物——而那恰恰是 L9/L0 在做的事。**

这引出本提案最重要的判断：

> **L10 作为"独立校准器"在原理上不成立。** 它能把已知的粗位置精修到 0.03px，但它无法自己回答"在哪个周期里"。

## 3. 三个候选方向（请裁决）

### 方向 A · 降级为"精修器"，不再是校准器 ⭐ 推荐

**定位改变**：L10 不产出 `CoordinateFrame`，而是在 L9/L0 已解出粗映射后，**投射规则光栅把残差压到亚像素**。

- 歧义问题消失：粗位置已知，只需 `mod period` 范围内的修正，且 L9 实测残差 0.000px、误差远小于半个周期。
- 用它最强的部分（0.03px 相位精度、抗壁纸污染），回避它最弱的部分（无法独立定位）。
- 与原则相容：仍是"自己投射 + 自己截屏 + 自己解算"。

**代价与疑问**：
- L9 当前实测残差已是 **0.000px / rms 0.000px**——**精修的收益可能为零**。
- 因此**必须先回答**：在什么环境下 L9 残差不为 0？分数缩放（1.25×/1.5×）、旋转输出、多显示器拼接——这些我**没有实机**可测。
- 若找不到"L9 不够准"的真实场景，**方向 A 也应当否决**（否则就是 AGENTS §7 的"骗人的旋钮"，只不过是模块级的）。

### 方向 B · 保留想法，但明确标注为"未验证构想"，暂不实现

把 §4.2 改写为本提案 §1 的实测结论 + "若要复活需先解决歧义"的说明，P3 转向别的目标。

- 最诚实、成本最低。
- 缺点：P3 就空了，需要另选目标（见 §5）。

### 方向 C · 重新设计：用**多频光栅**自解歧义

投射 2–3 个互质周期的光栅（如 37px / 41px / 43px），用**中国剩余定理**消歧：

- 组合周期 = 37×41×43 = **65231px**，远超任何屏幕宽度 → 全局唯一；
- 每个频率都是规则光栅 → 保留尖锐主频与 0.03px 相位精度；
- 这是测量学成熟手段（多频外差干涉、结构光三维扫描的标准做法），不是我现编的。

**但请注意**：这已经**不是** v0.4 的"对数螺旋渐变场"了，只是沿用了 L10 的编号。若选 C，应当视为**新提案**，走完整流程，且需回答与方向 A 相同的问题——**L9 已经 0.000px，多频光栅要解决谁的问题？**

## 附录 · 复现脚本

```python
import numpy as np
W,H=1366,768; P=40.0

def grating(shape,period,dx=0.0):
    h,w=shape; y,x=np.mgrid[0:h,0:w].astype(np.float64)
    return 127+100*np.sin(2*np.pi*(x-dx)/period)

def logspiral(shape,k=30.0,dx=0.0):
    h,w=shape; y,x=np.mgrid[0:h,0:w].astype(np.float64)
    cx,cy=w/2+dx,h/2; r=np.hypot(x-cx,y-cy)+1.0
    return 127+100*np.sin(k*np.log(r))

def est_phase(img,period):
    h,w=img.shape; y,x=np.mgrid[0:h,0:w].astype(np.float64)
    ref=np.exp(-2j*np.pi*x/period)
    return np.angle(np.sum((img-img.mean())*ref))

# 峰锐度
def sharpness(img):
    F=np.fft.fftshift(np.abs(np.fft.fft2(img-img.mean())))
    cy,cx=np.array(F.shape)//2; F[cy-3:cy+4,cx-3:cx+4]=0
    iy,ix=np.unravel_index(np.argmax(F),F.shape)
    r=np.hypot(ix-cx,iy-cy)
    yy,xx=np.mgrid[0:F.shape[0],0:F.shape[1]]
    ring=np.abs(np.hypot(xx-cx,yy-cy)-r)<1.5
    return F.max()/(F[ring].mean()+1e-12)

# --- 断言式自检：每条声称都在这里被验算 ---
sr = sharpness(grating((H,W),P))
assert sr > 200, sr
print(f"[1.1] 规则光栅锐度 {sr:.1f}  (提案: 250.9)")

for k in [10,20,30,50,80]:
    sl = sharpness(logspiral((H,W),k))
    assert sl < 10, (k, sl)
    print(f"[1.1] 对数螺旋 k={k:<3d} 锐度 {sl:.1f}  (提案: 3.4-6.8)")

ph0=est_phase(grating((H,W),P,0.0),P)
mx=0.0
for dx in [1.0,3.7,10.0,17.3,39.0]:
    d=(-(est_phase(grating((H,W),P,dx),P)-ph0)*P/(2*np.pi))%P
    mx=max(mx, min(abs(d-dx),abs(d-dx+P),abs(d-dx-P)))
assert mx < 0.035, mx
print(f"[1.2] 相位反推最大误差 {mx:.4f} px  (提案: <0.035)")

rng=np.random.default_rng(0)
wp=rng.normal(0,150,(H,W))
ref=0.5*grating((H,W),P,0.0)+0.5*(127+wp)
img=0.5*grating((H,W),P,7.0)+0.5*(127+wp)
d=(-(est_phase(img,P)-est_phase(ref,P))*P/(2*np.pi))%P
e=min(abs(d-7.0),abs(d-7.0+P),abs(d-7.0-P))
assert e < 0.1, e
print(f"[1.2] 强纹理壁纸下误差 {e:.4f} px  (提案: <0.06)  <- 抗噪, 非障碍")

base=est_phase(grating((H,W),P,0.0),P)
for dx in [40.0,80.0,120.0]:
    delta=abs(est_phase(grating((H,W),P,dx),P)-base)
    assert delta < 1e-12, (dx, delta)
print("[1.3] 整周期位移对相位不可见 (差 <1e-12 rad)  <- 致命伤")
print("\n全部断言通过：提案中的数字可复现。")
```
